Загрузите выгрузки

Файлы разбираются прямо в браузере. На сайте после входа через Google разобранные данные синхронизируются через ваш Google Диск; локальный файл работает без интернета и ничего не отправляет. Можно загружать всё сразу, в любом порядке — тип файла определится сам. Исходные выгрузки лежат в папке raw.

  1. Garmin (raw\garmin) — полный экспорт аккаунта: garmin.com/account/datamanagement → «Экспорт данных». Ссылка на ZIP придёт на почту через 24–48 часов. Загружайте ZIP целиком, распаковывать не нужно.
  2. Picooc (raw\picooc) — в приложении экспорт истории измерений: файл весов и файл давления.
  3. Анализы — шаблон raw\labs\labs.xlsx: впишите значения и загрузите.
  4. План тренировок — training\plan.json: один раз, дальше он хранится в ваших данных.
  5. Трекер — копия отметок training\tracker\tracker_….json, если браузер потерял данные.
Перетащите файлы в это окно
Каждая новая выгрузка Garmin и Picooc содержит всю историю — просто загрузите свежие файлы, старые данные обновятся. Данные сохраняются в этом браузере; исходные файлы держите в папке raw/.
